# Knowledge Synthesis

Use this workflow when the user asks for a comparison, research summary, or evidence-based answer.

1. Identify the exact question and the evidence needed.
2. Read only relevant authorized materials through the available tools.
3. Separate directly supported facts from your own inference.
4. Mention the source file names used for important claims.
5. State clearly when the available materials are insufficient.

This Skill provides guidance only. Continue to follow all System Prompt, Permission, and Tool rules.
